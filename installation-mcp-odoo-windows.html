Installation de l'assistant Odoo pour Claude

Guide rapide — Windows

Ce guide installe et configure automatiquement la connexion entre Claude Desktop et votre instance Odoo. L'ensemble prend moins de deux minutes.

1 Ouvrir PowerShell

Appuie sur + R, tape powershell, puis Entrée.

2 Coller la commande d'installation

Dans la fenêtre PowerShell qui s'ouvre, colle cette commande puis appuie sur Entrée :

irm https://raw.githubusercontent.com/AMA-Nalios/mcp-odoo-install/main/install-mcp-odoo-windows.ps1 | iex

3 Répondre aux questions

Le script installe automatiquement les outils nécessaires puis demande les informations suivantes :

URL OdooAdresse de ton instance, ex. https://nalios.odoo.com
Base de donnéesVisible dans le sélecteur de base au login, ou dans l'URL
Email / utilisateurTon identifiant de connexion Odoo
Clé APIOdoo > profil > Compte > Sécurité du compte > Nouvelle clé API

4 Redémarrer Claude Desktop

Une fois le script terminé ("=== Termine ==="), redémarre entièrement Claude Desktop pour activer le serveur MCP.

Important : fermer la fenêtre ne suffit pas — Claude Desktop reste actif en arrière-plan. Ouvre le Gestionnaire des tâches (Ctrl + Maj + Échap), trouve Claude, clique sur Fin de tâche, puis relance l'application.

En cas de problème

Si le script échoue ou si Claude Desktop n'est pas détecté automatiquement, contacte le support Nalios : ama@nalios.be.
